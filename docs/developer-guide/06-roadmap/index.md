# Project Roadmap

This page tracks the strategic evolution of **Kroki-rs**. For granular bug tracking, see [Technical Debt](#kroki-rs.developer-guide.tech-debt).

## v0.0.5: Stability & Parity (Current)
- [x] Full Decoupling of PlantUML/CheerpJ.
- [x] Content-addressed CI Image partitioning.
- [x] Professional `dflow` CLI orchestration.
- [x] Stable multi-arch distributions.

## v0.0.6: Performance & Scale (Next)
- [ ] Integration of `sccache` into GHA pipelines.
- [ ] Adaptive browser pool resizing.
- [ ] Enhanced Prometheus metrics for all providers.
- [ ] Native WebP conversion for all output types.

## v0.1.0: Core Maturity
- [ ] Official Homebrew Tap.
- [ ] Plug-in architecture for community-driven providers.
- [ ] High-concurrency stress verification (Load Testing).
